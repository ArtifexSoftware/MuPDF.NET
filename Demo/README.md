# MuPDF.NET Demo

First-run sample in this repository. It creates a one-page PDF with `TextWriter`, saves it, then opens it again and prints the path and page text.

It does **not** use MuPDF.NET.Office, a license key, or extra input files.

## Run

From the repository root:

```powershell
dotnet run --project Demo
```

Output: `Demo/Output/hello.pdf`.

## More samples

Feature tours (annotations, Office, Markdown, RAG, …) are in [MuPDF.NET.Examples](https://github.com/ArtifexSoftware/MuPDF.NET.Examples). Documentation: [MuPDF.NET examples](https://mupdfnet.readthedocs.io/en/latest/examples/index.html).
