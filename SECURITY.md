# Security Policy

## Supported versions

Use the current [MuPDF.NET](https://www.nuget.org/packages/MuPDF.NET) package from nuget.org (see [`Versions.props`](Versions.props) in this repo).

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security-sensitive reports.

Contact Artifex Software, Inc.:

- https://artifex.com/contact/mupdf-net
- Or your existing Artifex support channel if you are a commercial licensee

Include the package version, OS/.NET version, and steps to reproduce when possible.
